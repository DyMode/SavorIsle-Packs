# 味屿资源包

资源包包括厨房基础资料和分类菜谱。基础资料用于品牌、食材、产品和厨具记录；菜谱下载后先核对，再加入家庭配方库。

应用：[味屿](https://github.com/DyMode/SavorIsle)。索引地址：`https://raw.githubusercontent.com/DyMode/SavorIsle-Packs/main/index.json`。

## 分类菜谱

13个分类，144道带图配方；完整材料、步骤和来源均随ZIP保留。分类清单与原作链接见 [菜谱内容清单](recipes/CONTENTS.md)。菜谱目录为 [recipes/index.json](recipes/index.json)，基础资料继续使用原 `index.json`，两种内容格式分别保留。

应用中从配方页“菜谱资源包”或新增配方中的“从菜谱资源包添加”进入，可单包下载或下载全部。下载后统一核对确认，已有配方跳过；家庭修改和回收站内容保留，更新需确认，不覆盖自建内容。普通ZIP导入与导出继续可用。

## 下载与管理

具备资源包权益即可从应用入口下载全部基础资料及菜谱包，有效体验与正式臻享的范围相同。文件公开托管，应用保留完整导入与导出功能；权益校验约束应用获取入口。第三方内容的复制与使用仍须遵守原权利人的许可，本仓库不授予额外许可。内置基础资料与家庭自建资料可直接使用；权益过期后，已有配方中的资料快照仍可查看。

管理员可下载、同步或删除资料包，包内条目可按需启用或停用。同步保留停用设置；删除包后，其条目从资料选择中移除，已有配方快照和家庭自建资料保留。重新下载恢复条目并更新内容。

资料源入口为 [index.json](index.json)，包含包标识、版本、分类和条目。
